Timestamp microservice

Convert a Unix timestamp in seconds or a natural date to a UTC date.

Example: /api/ts/1451606400 or /api/ts/January 1, 2016.

{ "unix": 1451606400, "natural": "January 01, 2016" }

Use /api/ts for the current time. Invalid dates return null for both fields.

Aliases: /api/timestamp, /api/timestring and /api/v1/ts.
